## 环境准备

### 1. 检查系统环境

```bash
# 检查系统版本
cat /etc/os-release

# 检查 Python 版本
python3 --version

# 检查 OpenSSL 版本
openssl version
```

### 2. 关键依赖检查

**⚠️ 重要：Python 需要支持 SSL 模块**

```bash
# 检查 Python SSL 模块
python3 -c "import ssl; print(ssl.OPENSSL_VERSION)"
```

如果报错 `ModuleNotFoundError: No module named '_ssl'`，说明 Python 缺少 SSL 支持，需要重新编译 Python。

## 部署步骤

### 步骤 1：上传部署包

```bash
# 创建目录
mkdir -p /home/ai-app/oh-enterprise-1.0.0

# 解压部署包
tar -xzf oh-enterprise-1.0.0.tar.gz -C /home/ai-app/
cd /home/ai-app/oh-enterprise-1.0.0
```

### 步骤 2：安装 OpenSSL 1.1.1（如果系统版本过低）

**适用场景**：系统 OpenSSL 版本低于 1.1.1，导致 Python SSL 模块无法工作。

```bash
# 创建编译目录
mkdir -p /home/ai-app/openssl-build
cd /home/ai-app/openssl-build

# 下载 OpenSSL 1.1.1w（或从本地上传）
# 上传命令：sftp put openssl-1.1.1w.tar.gz

# 解压
tar -xzf openssl-1.1.1w.tar.gz
cd openssl-1.1.1w

# 配置
./config --prefix=/home/ai-app/openssl-1.1.1 --openssldir=/home/ai-app/openssl-1.1.1/ssl shared

# 编译安装
make -j4
make install

# 验证
LD_LIBRARY_PATH=/home/ai-app/openssl-1.1.1/lib /home/ai-app/openssl-1.1.1/bin/openssl version
# 输出: OpenSSL 1.1.1w  11 Sep 2023
```

### 步骤 3：编译 Python 3.12（支持 SSL）

**适用场景**：系统 Python 缺少 SSL 模块。

```bash
# 创建编译目录
mkdir -p /home/ai-app/python-build
cd /home/ai-app/python-build

# 复制或下载 Python 源码
cp -r /path/to/Python-3.12.12 ./
cd Python-3.12.12

# 设置环境变量
export PATH="/home/ai-app/openssl-1.1.1/bin:$PATH"
export LD_LIBRARY_PATH="/home/ai-app/openssl-1.1.1/lib:$LD_LIBRARY_PATH"
export CFLAGS="-I/home/ai-app/openssl-1.1.1/include"
export LDFLAGS="-L/home/ai-app/openssl-1.1.1/lib -Wl,-rpath,/home/ai-app/openssl-1.1.1/lib"

# 配置
./configure --prefix=/home/ai-app/python3.12-ssl \
    --with-openssl=/home/ai-app/openssl-1.1.1 \
    --with-openssl-rpath=auto \
    --disable-optimizations \
    --disable-profile

# 编译安装
make -j4
make install

# 验证 SSL
export LD_LIBRARY_PATH=/home/ai-app/openssl-1.1.1/lib:$LD_LIBRARY_PATH
/home/ai-app/python3.12-ssl/bin/python3 -c "import ssl; print('SSL OK:', ssl.OPENSSL_VERSION)"
# 输出: SSL OK: OpenSSL 1.1.1w  11 Sep 2023
```

### 步骤 4：创建虚拟环境

```bash
cd /home/ai-app/oh-enterprise-1.0.0

# 使用支持 SSL 的 Python 创建虚拟环境
export LD_LIBRARY_PATH=/home/ai-app/openssl-1.1.1/lib:$LD_LIBRARY_PATH
/home/ai-app/python3.12-ssl/bin/python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate
```

### 步骤 5：安装依赖

```bash
# 设置 SSL 库路径
export LD_LIBRARY_PATH=/home/ai-app/openssl-1.1.1/lib:$LD_LIBRARY_PATH

# 升级 pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt

# 验证关键依赖
python -c "import fastapi, uvicorn, websockets; print('Dependencies OK')"
```

### 步骤 6：创建数据目录

```bash
mkdir -p ~/.oh-enterprise/users
mkdir -p ~/.oh-enterprise/shared/skills
mkdir -p ~/.oh-enterprise/logs
```

### 步骤 7：配置环境变量

```bash
# 创建 .env 文件
cat > .env << 'EOF'
# LLM 配置
ANTHROPIC_AUTH_TOKEN=your-api-key-here
ANTHROPIC_BASE_URL=https://coding.dashscope.aliyuncs.com/apps/anthropic
ANTHROPIC_MODEL=glm-5

# 服务配置
PORT=8000
HOST=0.0.0.0
EOF
```

### 步骤 8：启动服务

```bash
cd /home/ai-app/oh-enterprise-1.0.0
source venv/bin/activate
export LD_LIBRARY_PATH=/home/ai-app/openssl-1.1.1/lib:$LD_LIBRARY_PATH

# 后台启动
nohup uvicorn openharness.enterprise.server:app --host 0.0.0.0 --port 8000 > ~/.oh-enterprise/logs/server.log 2>&1 &

# 查看日志
tail -f ~/.oh-enterprise/logs/server.log

# 验证服务
curl http://localhost:8000/health
```

## 常见问题

### 问题 1：Python 缺少 SSL 模块

**错误信息**：
```
ModuleNotFoundError: No module named '_ssl'
```

**原因**：Python 编译时未链接 OpenSSL 库，或系统 OpenSSL 版本过低。

**解决方案**：
1. 编译安装 OpenSSL 1.1.1+
2. 重新编译 Python，指定 `--with-openssl` 参数

---

### 问题 2：pip 无法安装包

**错误信息**：
```
SSLError("Can't connect to HTTPS URL because the SSL module is not available.")
```

**原因**：Python 缺少 SSL 模块。

**解决方案**：参考问题 1，重新编译 Python。

---

### 问题 3：WebSocket 连接失败

**错误信息**：
```
WebSocket connection to 'ws://xxx/ws/chat' failed
```

**原因**：`websockets` 库未安装。

**解决方案**：
```bash
pip install websockets
```

---

### 问题 4：SQLite 语法错误

**错误信息**：
```
sqlite3.OperationalError: no such column: TRUE
```

**原因**：SQLite 不支持 `TRUE`/`FALSE` 关键字。

**解决方案**：修改代码，将 `TRUE` 替换为 `1`，`FALSE` 替换为 `0`。

```bash
sed -i 's/= TRUE/= 1/g' openharness/enterprise/storage/database.py
sed -i 's/= FALSE/= 0/g' openharness/enterprise/storage/database.py
```

---

### 问题 5：前端页面空白

**错误信息**：浏览器控制台报 `404` 加载 CSS/JS 失败

**原因**：静态文件路径配置错误。

**解决方案**：
检查 `server.py` 中的 `WEB_DIR` 路径计算：
```python
# 正确（3 个 parent）
WEB_DIR = Path(__file__).parent.parent.parent / "web"

# 错误（4 个 parent）
# WEB_DIR = Path(__file__).parent.parent.parent.parent / "web"
```

---

### 问题 6：管理后台 404

**错误信息**：访问 `/admin` 返回 `{"detail":"Not Found"}`

**原因**：未配置 SPA 路由。

**解决方案**：在 `server.py` 中添加 SPA 路由：
```python
@app.get("/admin")
async def admin_spa():
    return FileResponse(str(WEB_DIR / "index.html"))

@app.get("/chat")
async def chat_spa():
    return FileResponse(str(WEB_DIR / "index.html"))
```

---

### 问题 7：模块导入失败

**错误信息**：
```
ModuleNotFoundError: No module named 'openharness.enterprise.channels'
```

**原因**：部署包中缺少部分模块。

**解决方案**：从开发环境复制完整的 `openharness/enterprise/` 目录。

## 维护命令

### 服务管理

```bash
# 启动服务
cd /home/ai-app/oh-enterprise-1.0.0
source venv/bin/activate
export LD_LIBRARY_PATH=/home/ai-app/openssl-1.1.1/lib:$LD_LIBRARY_PATH
uvicorn openharness.enterprise.server:app --host 0.0.0.0 --port 8000

# 后台启动
nohup uvicorn openharness.enterprise.server:app --host 0.0.0.0 --port 8000 > ~/.oh-enterprise/logs/server.log 2>&1 &

# 停止服务
pkill -f 'uvicorn.*openharness'

# 查看日志
tail -f ~/.oh-enterprise/logs/server.log

# 查看进程
ps aux | grep uvicorn

# 检查端口
netstat -tlnp | grep 8000
```

### 健康检查

```bash
# 健康检查
curl http://localhost:8000/health

# 测试登录
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 测试 WebSocket
curl -i -N -H "Connection: Upgrade" -H "Upgrade: websocket" \
  -H "Sec-WebSocket-Key: test" -H "Sec-WebSocket-Version: 13" \
  "http://localhost:8000/ws/chat?token=test"
```
